# 紫禁城 · 万里长城 | 3D 数字全景（IT 风格）

以 **IT 科技 / 数字孪生大屏风格** 呈现的故宫（紫禁城）+ 万里长城 双世界 3D 全景。
全部场景 **Three.js 程序化建模 + 程序化纹理**，零外部模型/图片资源，单文件运行。

## 运行方式

**方式一：直接打开** —— 双击 `index.html`（Three.js 已本地化于 `vendor/`，**离线可用**）。

**展陈模式（Kiosk）**：底部「展陈」按钮 → 全屏 + 隐藏 UI + 自动循环导览（全场景 → 逐视点开卡讲解 → 双世界轮换），观众操作即暂停、闲置自动恢复，页面异常自动重载。适用于触控一体机常驻展示。

**光照预设**：夜（数字孪生夜景）/ 晨（暖调低光）/ 昼（考证观展），底部工具栏「夜/晨/昼」切换。

**双语**：顶部「EN/中」一键切换，29 条视点说明均配英文。

**方式二：本地服务器（推荐）**
```bash
cd ai-gugong3d
python -m http.server 8123
# 浏览器访问 http://localhost:8123
```

## 世界一：紫禁城（19 处标注）

午门（五凤楼）→ 内金水桥×5 → 太和门 → **三大殿**（太和殿·重檐庑殿 / 中和殿·四角攒尖 / 保和殿，共享三层汉白玉台基）→ 乾清门 → **后三宫**（乾清宫 / 交泰殿 / 坤宁宫）→ 御花园·钦安殿 → 神武门，另有东华门、西华门、四座角楼、东六宫/西六宫、文华殿/武英殿、护城河、景山。

**可进入内景**：点击「太和殿」或「乾清宫」标注 → 信息卡内点击「进入殿内」——金砖墁地、井字天花彩画、三重藻井、髹金雕龙宝座、"建极绥猷"匾（乾清宫为"正大光明"）、楹联、地毯、柱础，纤毫毕现。

### 精细度（每一块砖都看得到）

| 部位 | 实现方式 |
|---|---|
| 朱红宫墙 | 抹灰罩面程序化纹理：抹痕起伏 + 雨痕流坠 + 泛碱 + 局部剥落露灰，砖线压在灰浆下隐约可辨 |
| 长城灰砖 | 程序化砖缝纹理，不同尺寸墙体自动匹配砖缝密度 |
| 城台门洞 | 半圆券洞 + 汉白玉券脸，随城台收分斜面倾斜；洞内有 BackSide 棱券（穿门时不会"在实心墙里看穿两侧"），碰撞体沿长轴按三券断开，第一人称真的能推门而过。券洞外即护城河且无桥，故河环带注册为碰撞体——穿门走到河岸即止，不会踏水。城墙端点与城台底边搭接（原来午门两侧各留 2.9m 亮缝） |
| 城楼 / 角楼 | 午门五凤楼：正楼加宽到 84（原 62 只占 123 宽城台的一半）改重檐庑殿，两翼雁翅楼顶补廊庑（彩画枋 + 双跳出跳斗拱 + 顺脊长瓦顶），翼端阙亭改重檐攒尖；太和门/神武门/东华门/西华门门楼改**重檐**（太和门、乾清门带歇山山花），城台顶加一圈女墙压出轮廓。角楼改**十字抱厦**：中心方身四面出抱厦，三重十字脊大檐（两向庑殿交叉）+ 宝顶——原来是三层方盒子逐层收小，远看只是一座小塔 |
| 广场墁砖 | 青砖十字对缝，按分区实际尺寸换算砖块密度（单砖约 0.6m）；昼档底色压到中性暖灰 0xaba69b（原 0xd6d0c4 近白，大视距下整片中轴糊成白板、砖缝全丢） |
| 内金水桥 | 单孔半椭圆石拱（券脸挤出成实体，桥下真正通透可观水），两侧汉白玉栏板 + 望柱 + 石榴头柱头，两端桥堋四级踏跺落到广场；河槽是石壁深槽（底 -2.4、水面 -1.1、堤顶 1.2，券顶略出堤），五桥位/宽度/桥面高度由一张 `JINSHUI` 表统一驱动 |
| 琉璃瓦 / 灰瓦 | 筒瓦为顺坡通长的垄（贴图沿檐口方向排布），四坡各自按周长与斜距展 UV，垄向始终垂直檐口 |
| 台基 | 汉白玉石条错缝纹理 + 逐根 instanced 望柱与栏板 |
| 檐下 | 彩画枋 + 双跳出跳斗拱（instanced）+ 飞檐翘角 |
| 大门 | 朱漆门钉纹理（横九路竖九路金钉） |
| 室内 | 金砖反光地面、藻井宝珠、金漆宝座、楹联、地毯、柱础 |
| 陈设 | 鎏金铜缸、日晷×2、铜龟、铜鹤（太和殿），华表一对（午门外） |
| 匾额 | Canvas 绘制"正大光明"楷体金字 |
| 院落 | 东六宫/西六宫合院加深（进深 d+34）：前殿南移、后院补后殿与南墙宫门，12 院的附属建筑按材质合并（仅 +4 draw call）；文华殿/武英殿各自围合院墙与月门 |
| 植被 | 古柏（裸干 + 窄柱状密冠）/ 宫槐（分叉主枝 + 阔卵冠）两类；冠团一律用二十面体加大抖动取参差轮廓（光滑球无论怎么堆都像"气球/菜堆"），根颈外张让树落在地上；分带 InstancedMesh |
| 御花园 | 红墙围合的完整园子：中轴钦安殿（汉白玉栏板台基 + 天一门），东西万春亭/千秋亭重檐攒尖对置，东北堆秀山叠石 + 山顶御景亭，西北两层延晖阁，东西浮碧亭/澄瑞亭跨池而建（石桥连岸），南墙坤宁门、北墙顺贞门；细石子甬路面随光照档位分档着色（夜景不泛白），太湖石组与沿墙古柏错落。原来只有一座钦安殿 + 一片锥形树，POI 看过去是"空广场" |
| 景山 | 五峰五亭：一道低宽基座脊 + 五座"x 半径小于峰间距"的椭穹按 max 复合——此前主峰 x 半径 134 把辅峰整个吞掉，读起来是一整块椭圆煎饼；加基座后鞍部不再落回地面，五顶各自成形又连成一条脊。表面用双线性插值的三倍频平滑值噪声（原按整数格哈希而顶点间距约 9 单位＝逐顶点随机，法线一平均就糊成光滑绿馒头），山脚一圈石砌护坡，满坡 340 株矮松按同一 `surfY` 落位；五亭高度也由 `surfY` 算出，不再写死 y 值 |
| 氛围 | 夜空明月（不受雾衰减）、护城河水光呼吸、软阴影 |

## 世界二：万里长城（10 处标注）

程序化燕山山脊地形（低多边形 + 顶点色分层；顶点色是为数字孪生夜景压暗的，昼/晨按档位抬反照率并略加暖，白天不再是炭黑山）+ 沿山脊蜿蜒 2300 单位的长城：
关城（U 形瓮城 + 偏门 + 两层城楼）、敌楼（四面箭窗 / 北四楼 / 北八楼 / 东端敌楼）、烽火台（台身门洞与箭窗、狼烟火光脉动）、好汉坡。
垛口/山坡松林（950 株，落位上限放到 h<120，墙两侧上半坡也有林）InstancedMesh，墙体为沿山脊连续条带几何（合批到位：长城侧单帧只有数十次 draw call）。
阴影相机沿墙走向量化跟随（正交取景只有 ±560，而墙长 2320，不跟随则半条墙落在阴影贴图之外）。
**长城世界懒加载**：入场飞行结束后分帧砌造（生成器切片，每片 ≤~60ms），启动不再等它；提前切换世界会同步收尾，无感。

> 单帧实测负载（无头 Edge + SwiftShader / 1600×900；每次采样前重置 `renderer.info`，取稳定重复值；
> 相对第十九轮为同方法论同机位对比）：
>
> | 视点 | 改造前 | 改造后 | draw call 变化 |
> |---|---|---|---|
> | 紫禁城 · 全景 | 2,238 / 59.9 万 | **1,036 / 57.2 万** | **-54%** |
> | 紫禁城 · 太和殿近景 | 1,280 / 38.2 万 | **762 / 45.8 万** | -40% |
> | 紫禁城 · 太和殿内景 | 881 / 32.0 万 | **699 / 46.0 万** | -21% |
> | 紫禁城 · 檐角斗拱特写 | 331 / 12.4 万 | **311 / 18.0 万** | -6% |
> | 长城 · 全景 | 85 / 25.8 万 | **101 / 26.6 万** | +16（见下） |
> | 长城 · 好汉坡 | 36 / 25.1 万 | **73 / 25.8 万** | +37（见下） |
>
> 第二十轮合批改造：柱列（344 根→每殿 1 个 InstancedMesh）、紫禁城树木（59 组独立几何→分带实例化）、
> 飞檐翘角（每殿 4→1）、斗拱（6 InstancedMesh→2，层间变换烘进几何）、门窗/格扇/壁柱/撩檐枋/栏板/
> 压顶石/桥体/院墙/敌楼门洞按材质合并、描边线段（~140 个→每世界 1~2 个）、box() 几何缓存。
> 长城侧 +16/+37 来自合并件包围盒变大后个别原先被剔除的小件进入视锥，绝对量仍是数十次 draw call。
> 斗拱特写三角面 +5.6 万为树木实例化的取舍：分带后特写机位仍会提交所在带的全部树，换来全景 -1,200 draw call。
> 昼档 bloom 直接关闭（strength=.14/thr=1.05 本就无输出，省 5 级 mip 后处理链）；夜档水面反射降为 5s 一捕。

## 自定义

- **配色**：改 `<style>` 中 `--cyan / --gold` 与 JS 材质区。
- **标注**：增删 `POIS_G / POIS_W` 数组（名称、坐标、简介、飞行落点、`inner` 内景）。
- **建筑**：`palace()` 生成器支持台基层数、重檐、攒尖、内景、斗拱等参数。
- **地形**：改 `terrainH()` 的高度场函数即可重塑山川。

## 技术栈

Three.js r170（importmap + ES Module，本地 vendor 目录，离线可用）、EffectComposer + UnrealBloomPass、ACES 色调映射、CanvasTexture 程序化纹理、InstancedMesh 批渲染（柱列/斗拱/树木/垛口/人群/瓦当）、生成器分帧懒加载（长城世界）、按材质几何合并 + 描边烘接、Catmull-Rom 巡航样条、手写 CSS2D 投影标注。
